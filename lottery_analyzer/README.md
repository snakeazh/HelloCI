# 🎯 彩票号码分布分析工具

自定义分析规则，回测验证你的选号思路正确率。

## 功能特性

- **号码分布统计** — 可视化红球/蓝球出现频率
- **7种分析规则** — 冷热号、间隔期、和值、奇偶比、连号、区间比、重号
- **回测验证** — 用历史数据验证规则正确率
- **支持双色球/大乐透** — 两种主流玩法

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 生成示例数据
python3 generate_sample_data.py

# 启动应用
python3 app.py
```

打开浏览器访问 http://localhost:5000

## 分析规则

| 规则 | 说明 |
|------|------|
| 冷热号分析 | 根据近N期频率选择热号/冷号 |
| 间隔期数分析 | 找出超过平均出现间隔的号码 |
| 和值范围分析 | 统计红球和值的分布区间 |
| 奇偶比分析 | 分析奇偶数比例规律 |
| 连号分析 | 统计连续号码出现模式 |
| 区间比分析 | 各号码区间的出号比例 |
| 重号分析 | 与上期重复号码的规律 |

## API 接口

- `GET /api/lottery_types` — 获取支持的彩票类型
- `GET /api/history/<type>` — 获取历史数据
- `GET /api/distribution/<type>?zone=red|blue` — 号码分布
- `GET /api/rules` — 获取可用分析规则
- `POST /api/analyze` — 执行分析
- `POST /api/backtest` — 回测验证

## 如何使用自定义思路

1. 选择彩票类型（双色球/大乐透）
2. 选择分析规则并调整参数
3. 点击"执行分析"查看预测结果
4. 点击"回测验证"查看历史正确率
5. 对比不同规则和参数组合，找到最优策略
